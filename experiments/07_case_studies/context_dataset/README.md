# Public context dataset study (Kaupp et al., Zenodo 4034867)

Read-only feasibility study of a public industrial context dataset:

* source: `https://zenodo.org/records/4034867`, DOI `10.5281/zenodo.4034867`,
  archive `kaupp_context_dataset.zip`, MD5
  `ca10ec210b91159811f72959a868bade`, size 23,474,033 bytes;
* license: **CC BY-NC 4.0** — the dataset is not redistributed here;
  `scripts/download_context.py` fetches it from the original source and
  verifies the MD5 before extraction;
* **outcome:** the archive does not support a data-grounded task-completion
  Time Petri Net case (no product identity, no observable alphabet, no
  adjustment authority); evidence in `analysis_summary.md`;
* `results/` — summary tables and inventories used in the study;
* `scripts/` — download, extraction and analysis scripts.
