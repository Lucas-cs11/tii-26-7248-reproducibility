Read-only analysis of the public industrial context dataset:

* source: `https://zenodo.org/records/4034867`, DOI `10.5281/zenodo.4034867`,
  archive `kaupp_context_dataset.zip` (v2), MD5
  `ca10ec210b91159811f72959a868bade`, size 23,474,033 bytes;
* license: **CC BY-NC 4.0** — the dataset is **not** redistributed in this
  package; `scripts/download_context.py` fetches it from the original source
  and verifies the MD5 before extraction;
* reports: `results/G1_data_validation.md`, `G2_*`, `G3_*`, `G4_*`, `G5_*`,
  `P0_corrected_statistics.md`;
* `results/MANIFEST.sha256` covers the report files.
