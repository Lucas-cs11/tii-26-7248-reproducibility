# Public context dataset study (Kaupp et al., Zenodo 4034867)

Read-only analysis of a public industrial context dataset:

* source: `https://zenodo.org/records/4034867`, DOI `10.5281/zenodo.4034867`;
* archive `kaupp_context_dataset.zip`, MD5
  `ca10ec210b91159811f72959a868bade`, size 23,474,033 bytes;
* license: **CC BY-NC 4.0** — the dataset is not redistributed in this package;
  `scripts/download_context.py` fetches it from the original source and verifies
  the MD5 before extraction;
* the analysis scripts cover integrity verification, cycle reconstruction,
  event recovery, concurrency reclassification and timing semantics.

Curated from the archived companion repository `tii-context-case-study`; the
produced tables remain in that archive.
