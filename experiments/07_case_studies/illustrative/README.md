# Illustrative TPN case

Model, verifier source snapshot, scripts, results and figures for the
illustrative Time Petri Net used to introduce the diagnosis and
firing-interval-adjustment workflow.

Contents: `model/` (frozen net), `src/` (verifier snapshot used for this case),
`scripts/` (drivers), `results/` (verifier and adjustment outputs), `fig/`
(figures), `MANIFEST.sha256`.

Curated from the archived repository `tii-illustrative-tpn-case`; run the
scripts in `scripts/` from this folder.
