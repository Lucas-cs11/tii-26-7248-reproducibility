# Illustrative Time Petri Net case

Fixed net, driver scripts, results and figures for the illustrative Time Petri
Net used to introduce the diagnosis and firing-interval-adjustment workflow.

Contents: `model/` (fixed net), `src/` (verifier snapshot used for this case),
`scripts/` (drivers), `results/` (analysis and adjustment outputs), `fig/`
(figures), `MANIFEST.sha256`.

Run the scripts in `scripts/` from this folder; outputs are written under
`results/`.
