# TII-26-7248 — Reproducibility package

This repository contains the result files, pre-registered protocols and
execution code for the experiments of the paper *Bounded Task-Completion
Diagnosability of Time Petri Nets: Verification and Firing-Interval Adjustment*
(IEEE Transactions on Industrial Informatics, manuscript TII-26-7248).

## Results

| Experiment | Manuscript artifact | Result |
|---|---|---|
| Scalability of the bounded-diagnosability analysis | Fig. 6 | 8,280 pre-registered evaluations: 5,406 completed, 2,874 wall-clock-capped, 0 errors; verdicts VER 1,975 / AMB 2,782 / INC 649 |
| Implementation equivalence of the optimized verifier | — | 48 paired evaluations (30 conclusive and identical), 726,665 transition-level comparisons with 0 mismatches, 5 component audits with 0 mismatches |
| Per-case verifier runtimes | Fig. 3 | 36,450 evaluations, all completed; verdicts VER 20,412 / AMB 16,038; median 8.1 ms, P90 107 ms, P95 0.92 s, maximum 5.59 s |
| Ambiguity-horizon sensitivity | threshold figure | 15,288 AMB models (of the 16,038-model population), 76,440 (model, ratio) evaluations, 74,294 completed; threshold `H_amb*/H_base`: median 0.278, P05–P95 0.167–0.394 |
| One-step exhaustive firing-interval adjustment | adjustment table | full 16,038-evaluation AMB population: 2,001 verified successes, 11,314 finite-search failures, 2,683 wall-clock-capped, 40 errors |
| Historical-baseline audit | — | 3,645 archived evaluations recomputed with **0 verdict changes**; full second pass 1,956/1,956 |
| Case studies | case figures/tables | illustrative net; published nets (Wang/Mahulea/Silva, *IEEE TAC* 2015: 38 state classes / 63 edges, identical to TINA 4.0.0 `-W`); manufacturing subnet; public context dataset (outcome: not sufficient for a task-completion case) |

Timings are comparable only within the platform on which they were measured;
the scalability study was measured on one cloud CPU platform only.

## Reproduce

```bash
python -m pip install --require-hashes -r experiments/01_scalability/code/requirements.lock
(cd experiments/01_scalability/code && python -m unittest discover -s tests -p 'test_*.py')
```

Each experiment folder contains its protocol, its result files and the commands
needed to reproduce it. `REPRODUCE.md` gives the complete sequence.

## Verification

* Every result file is generated by the scripts shipped here; the analysis
  pipeline refuses to emit statistics when its integrity check fails.
* The independent audit recomputes every record hash and every pre-registered
  field from the raw records; its result is
  `experiments/01_scalability/results/audit.json` (PASS, 8,280 evaluations,
  8,280 unique identifiers, 120 partitions).
* The bulk raw scalability records (8,280 JSON records plus partition ledgers,
  metrics and hash manifests) are attached to this repository as the release
  asset `scalability-evaluations`.
* `MANIFEST.sha256` at the root covers every checked-in file.
